# Comparación de algoritmos de ordenamiento

El siguiente proyecto academico de Programación Avanzada compara el
rendimiento de MergeSort y QuickSort mediante experimentos
implementados en C++.

## Objetivo

Analizar el comportamiento de ambos algoritmos utilizando
diferentes tamaños y patrones de entrada, registrando tiempos
de ejecución y operaciones realizadas.

## Medios

- C++
- g++
- Git y GitHub

## Estado del proyecto
